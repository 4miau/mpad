# Mpad

This is my old project as my replacement to Windows 10 Notepad (Windows 11 now contains the features existing here), this uses a reference to a UI NuGet package I no longer use or possess so building and deploying would require you to need to remake the UI. At some point I may intend to make a project to combat the Windows 11 version however I had personal problems with Windows 10 which is why I made mpad, but I am a lot more content and satisfied with Windows 11 that I have less of a desire to do so, so it's likely this will stay deprecated and abandoned.
